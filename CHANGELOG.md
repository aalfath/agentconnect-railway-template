# Changelog

Each entry lists breaking changes first. Read it before you apply an update
from Railway's "update available" notice.

## 2.18.0 (2026-11-24)

- First release of this Railway template: AgentConnect v2.18.0 (control-plane,
  relay and web images pinned by tag and digest), Caddy 2.11.9 gateway with a
  generated login, Railway Postgres 18.
- Measured on Railway at 0.5 GB / 1 vCPU per service: Control Plane about
  250 MB, Relay and Web about 85 MB each, Gateway about 15 MB.
